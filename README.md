# S&YTech 事業紹介サイト

Stripe の事業確認（Activate your account）に提出するための、S&YTech の事業紹介サイト。
静的 HTML/CSS のみ。ビルド不要、JavaScript なし。

## 構成

```
index.html        LP 本体
                  ヒーロー＋事業サマリー → 01 ご相談の例 → 02 お作りするもの
                  → 03 お金の流れ → 04 運営者情報 → 05 お問い合わせ
tokushoho.html    特定商取引法に基づく表記
privacy.html      プライバシーポリシー
assets/style.css  スタイル一式
assets/favicon.svg
```

## デザインの決めごと

- 純白（`#FFFFFF`）基調。面・影・カードは使わず、余白と細い罫で構造をつくる
- 全セクションが「左＝番号ラベル（スクロール追従）／右＝本文」の台帳レイアウト
- 色面はパイングリーン（`#0E5C4A`）1 色。塗りを使うのは「お金の流れ」の 1 ブロックのみ
  （ヘッダーの公式LINE ボタンと `#contact` の `.line-cta` は黒地／ホバーで緑）
- 書体：Murecho（和文・見出し）／ Space Grotesk（番号・欧文ラベル・メールアドレス）

## ローカルで確認する

```
python3 -m http.server 8080

```

## 注意

- **パスワード保護をかけないこと。** Stripe の要件（誰でも閲覧できること）。
- ページ内の表記「S&YTech」は Stripe 登録事業名と一致させること。変更しない。
- **完全紹介制**。ヒーローと 06 お問い合わせに `.badge` で明示し、公式LINE のボタンは
  「ご紹介を受けた方はこちら」と書いてある。誰でも申し込める形には戻さない。
- **決まった商品を並べない。** 01 はサービスの一覧ではなく「お客さまの状況」を主語に
  した相談例で、読んだ方が自分の状況を探せる形にしてある。02 の「たとえば」も
  メニューではなく例示。ここを機能一覧に戻すと、読み手が自分を当てはめられなくなる。
- 特定の業種（ネイル等）に限定する表現は使わない。
- 料金は「個別のお見積り」表記。金額はサイトに載せず、ご相談時に料金表をお渡しする。
  金額を載せる場合は `index.html` の 02 と `tokushoho.html` の「販売価格」を更新する。
- 導入事例（juju）はクライアント許諾が取れてから追加する。現状は未掲載。
- 代表者名は漢字「柴沼 勇太」。契約書・請求書と表記を揃えてある。変更する場合は
  `index.html`（サマリー・04）と `tokushoho.html`・`privacy.html` の 3 ファイル。
- 公式LINE の URL は `https://lin.ee/tbjOB0D`。掲載箇所は `index.html`（05 お問い合わせ）、
  `tokushoho.html`（公式LINEアカウント欄・フッター）、`privacy.html`（1. 取得する情報・
  9. お問い合わせ窓口・フッター）。変更時はこの 3 ファイルをまとめて更新する。
  トップのヘッダーとフッターからは外してある（紹介制のため入口を増やさない）。
