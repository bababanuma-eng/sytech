Why

技術があっても、売り場がなければ売上にはなりません。

ネイリストからよく聞く 3 つの詰まり方です。S&YTech が提供する 3 つの仕組みは、それぞれこの詰まりに対応しています。

フォロワーは増えたが、そこから先の受け皿がない。

→ ホームページ制作

Services

提供するもの

3 つをワンセットで制作し、公開後も運用を継続します。ネイルの施術・指導そのものは行いません。教材や講座の内容はすべてクライアントのものです。

01 / WEB

ホームページ制作

Instagram のプロフィールから来た人が、サービス内容を理解し、そのまま登録・購入まで進めるサイトを制作します。スマートフォンでの閲覧を前提に設計します。

  • サービス紹介・料金ページの構成と執筆
  • 会員登録・ログイン導線の実装
  • スマートフォン最適化
  • 公開後の内容更新
02 / LINE

公式LINEの自動育成

LINE Messaging API を使い、友だち追加後のメッセージを自動で配信します。段階的に内容を伝えたうえで、購入ページへ案内します。

  • 友だち追加後の自動メッセージ設計
  • 配信シナリオの作成と改善
  • 購入ページへの誘導設定
  • 手動での一斉配信にも対応
03 / VIDEO

動画の売り場

動画教材を販売し、購入者だけが視聴できる状態にするための一式です。会員管理から動画配信までを含みます。

  • 会員登録・ログイン
  • 月額サブスクリプションの販売
  • 単発動画の販売
  • 購入内容にもとづく視聴権限の管理
  • 動画配信・無料サンプルの公開
Payments

決済とお金の流れ

受講者が支払った代金は、S&YTech を経由せず、クライアントの口座に直接入金されます。S&YTech が受け取るのはプラットフォーム手数料のみです。

1. 支払う

受講者

クライアントのサイト上で、月額サブスクリプションまたは単発動画の代金をクレジットカードで支払います。

2. 受け取る

クライアント（ネイリスト）

クライアント名義の Stripe アカウントで決済され、売上はクライアントの銀行口座に入金されます。受講者に教材を提供するのもクライアントです。

3. 手数料

S&YTech

決済額に対するプラットフォーム手数料のみを受け取ります。売上そのものを預かることはありません。

  • 決済基盤には Stripe Connect（Express アカウント）を利用し、Direct charges で処理します。
  • クレジットカード情報は Stripe が処理し、S&YTech およびクライアントのサーバーには保存されません。
  • 受講者との契約当事者はクライアントです。S&YTech はその仕組みを制作・運用する立場です。
Pricing

料金の考え方

制作の範囲と運用の内容によって変わるため、個別にお見積りします。料金は次の 3 つで構成されます。

初期制作費

ホームページ、公式LINEの設定、動画の売り場の構築。着手前に一括で見積り、合意のうえで着手します。

個別見積り

月額利用料

公開後のサーバー・システムの維持、内容の更新、配信シナリオの改善、不具合対応。

個別見積り

決済手数料

動画教材の売上に対して発生するプラットフォーム手数料。売上がない月は発生しません。別途 Stripe の決済手数料がかかります。

売上に対する料率

金額はご相談内容にもとづいて算出し、契約前に電子メール等の書面で提示します。提示した金額に合意いただくまで、費用は一切発生しません。
